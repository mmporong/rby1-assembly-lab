# 기존 toy 과제의 실험 계약

이 문서의 76차원 관측·35 mm 삽입·정답 상태 기준 제어는 `configs/task.json`을 사용하는 기존 toy 과제의 계약이다. RJ45의 79차원 관측·고정 파지 추정기·초기화와 평가 계약은 [RJ45 과제 문서](rj45-task.md)를 따른다.

## 문제와 완료 기준

RB-Y1 M v1.2가 한 손에 하우징, 다른 손에 방향성이 있는 플러그를 잡고 상대 자세를 조절해 삽입한다. 삽입이 막히면 후퇴·재정렬·재삽입한다. 첫 실험에서는 베이스를 고정하고 두 팔의 기여를 분리해 평가한다.

부품은 자유 강체다. 그리퍼와 물체 사이에 고정 조인트, 키네마틱 추종, 매 스텝 위치 덮어쓰기를 넣지 않는다. 리셋에서만 초기 상태를 지정한다. 파지 후 접촉·상승·상대 위치를 검증한 에피소드가 조립 단계로 들어간다.

완료는 평가기가 실제 삽입 깊이, 횡방향 오차, 각도 오차, 유지 시간, 파지, 힘 제한, 금지 접촉을 함께 판정한다. 제어기의 `done` 단계나 보상값만으로 성공 처리하지 않는다. 수치와 단위는 `configs/task.json`에 둔다. 해당 수치는 시뮬레이션 설계 가정이며 제조사 허용 하중이나 실측 교정값이 아니다.

## 개발 순서

1. 공식 모델·그리퍼 및 공개 환경 에셋의 출처·해시·USD 물리 구성을 검사한다.
2. 한 환경에서 낙하·정지·그리퍼 개폐·부품 파지·조립을 실행한다.
3. 기준 제어기의 실패 조건을 고정하고 작은 양팔 보정량을 출력하는 잔차 정책을 학습한다.
4. 고정 지그, 지지팔 고정, 양팔 순응을 비교한다. 기준 제어기도 동일한 재시도 예산으로 비교한다.
5. 검증된 실행만 시연 데이터로 보존하고 필요에 따라 영상 관측 정책으로 확장한다.

현재 2단계에서 Isaac Sim·PhysX 장면과 RTX 렌더링, 양손 마찰 파지, 두 부품의 15 mm 이상 리프트와 nominal 삽입 완료를 확인했다. 단일 seed의 zero-residual 기준 제어기는 30.66 mm 깊이, 1.08 mm 횡오차, 0.4초 유지로 44.07초에 독립 성공 판정을 통과했다. 이때 삽입 하중은 0 N이어서 여유 끼워맞춤 기준선만 검증한다.

기준선 HDF5에는 서로 다른 3개 seed의 독립 성공·유효 episode가 있으며 train 2개·eval 1개로 결정적으로 분리된다. 학습 가능한 episode는 train 2개이고, 원본 source archive와 episode hash를 검증했다. 정본은 [기준선 데이터 근거](evidence/baseline-dataset.json)다. 이 기록의 소스·설정·에셋 해시는 당시 원본 소스 묶음과 대조한 값이다. 이후 RJ45 구현이 추가된 현재 소스와 같은 버전으로 간주하지 않는다.

3단계는 4환경·1 iteration·96 transition의 PPO runtime smoke까지 진행했다. 프로세스 정상 종료, 유한한 checkpoint tensor, optimizer 상태와 update는 확인했지만 전체 episode, 잼 회복, 정책 성공률은 확인하지 않았다. 따라서 개발 순서의 3단계를 완료했거나 잔차 정책이 기준 제어보다 낫다고 판정하지 않는다.

## 관측 경계

초기 상태 기반 학습은 잡음을 더한 시뮬레이터 자세를 사용하고 `simulator_state_with_noise`로 기록한다. RGB-D 추정기를 실행한 관측만 `estimated_pose`로 기록한다. 접촉 센서의 힘은 손목 6축 F/T 센서와 동일하지 않으므로 접촉력 대용값임을 명시한다. 평가용 정답 깊이·접촉과 정책의 관측을 각각 보관한다.

현재 잔차 정책과 달리 기준 제어기·단계 전환은 정답 상태를 사용한다. 이 구성의 성능을 센서 오차에 대한 전체 시스템의 강건성으로 해석하지 않는다. 향후 관측 추정기를 연결할 때 기준 제어기의 입력도 함께 교체해야 한다. 로봇은 고정 베이스이고 자체 충돌은 꺼져 있으므로 이동 베이스 결합이나 링크 간 충돌까지 검증한 결과가 아니다.

nominal 성공 근거는 seed `20261025` 한 건이다. 카메라는 외부 관찰 영상을 만들었을 뿐 제어 입력으로 사용하지 않았다. 따라서 이 실행으로 잼 회복, 강화학습 개선, 카메라 제어, 실물 적용을 주장하지 않는다. 0 N 삽입 하중은 접촉 측정 실패가 아니라 현재 형상의 여유 끼워맞춤에서 플러그와 소켓이 접촉하지 않았다는 실행 기록이며, 잼 조건은 간극·초기 오프셋·물성을 별도로 고정한 뒤 재검증해야 한다.

파지 하중은 각 손의 두 손가락과 해당 부품 사이 필터 접촉에서 계산한다. 삽입부는 월드 좌표계 법선 합력 벡터의 크기와 개별 접촉 법선력 절댓값의 합을 별도 채널로 저장하며, 잼·과부하 판정에는 개별 접촉 하중의 합을 사용한다. 금지 접촉은 29개 로봇 부위와 허용되지 않은 대상의 접촉 쌍별 법선 하중을 합산한다. 접촉 데이터가 포화되거나 비정상 값이 나오면 0 N으로 간주하지 않고 평가를 무효화한다. net force 기반 값은 진단용으로만 남긴다.

중력 보상은 모델 중력 항을 관절 강성으로 나눈 위치 편향 `g/Kp`를 implicit drive 목표에 더한다. 별도 effort 명령으로 actuator 힘 제한을 우회하지 않는다.

정렬 후에는 지지하는 하우징의 측정 자세를 삽입 좌표계로 삼는다. 기준 제어의 깊이 명령은 초당 4 mm로 증가하고 측정 깊이보다 최대 6 mm 앞선다. 횡·회전 오차에 따른 진행 보류에는 재개 기준을 따로 둔다. 이 로직 뒤에 정책 잔차가 더해지므로 정책 전체의 안전 보장으로 해석하지 않는다. 파지 손실은 연속 0.2초 이상일 때 실패로 처리하며, 성공 판정은 그 순간의 양손 접촉과 0.4초 유지 조건을 계속 요구한다.

정책 관측은 76차원이며 아래 순서로 기록한다. 초기 60·62차원 시험 파일은 현재 데이터 계약에서 거부한다.

| 인덱스 | 내용 | 단위·형식 |
| --- | --- | --- |
| 0–2 | 하우징 입구 기준 플러그 끝 위치 | m, 하우징 좌표계, 잡음 포함 |
| 3–6 | 두 부품의 상대 회전 | quaternion wxyz, 잡음 포함 |
| 7–20 / 21–34 | 양팔 14관절 위치 / 속도 | rad / rad/s |
| 35–36 | 손별 손가락 접촉력 최댓값 | N |
| 37 | 삽입부 개별 법선 하중의 합 | N |
| 38–39 | 양손 파지·상승 증명 | 0 또는 1 |
| 40–47 | 동작 단계 | 8차원 one-hot |
| 48–59 | 직전 제한된 잔차 행동 | 12차원, 정규화 값 |
| 60–61 | 삽입 깊이 명령 / 전진 허용 상태 | m / 0 또는 1 |
| 62–75 | 삽입 기준 제어기의 누적 관절 목표와 현재 위치 차이 | rad, 삽입 이외 단계는 0 |

삽입 중에는 기준 제어의 관절 보정만 누적해 하중에 따른 정상상태 오차를 줄인다. 누적 목표는 관절 강성·구동 한도·모델 중력 항으로 계산한 위치 편차와 관절 범위 안으로 제한한다. 정책 잔차는 누적하지 않고 해당 step의 목표 보정으로만 적용한다. 이 계산은 위치 구동 명령의 제한이며 실물 토크 측정이나 무포화 보장이 아니다.

보상은 성공 1회에 +10, 실패·시간 초과에 -2, 매 제어 step에 -0.01을 준다. 횡·회전 오차, 접촉 하중과 행동 크기를 감점하고 깊이 보상은 35 mm에서 제한한다. 파지 상태를 유지하는 것만으로 매 step 보상받던 항은 제거했다. 이 보상 설계와 학습 성능의 검증은 구분한다.

## 병렬 환경 격리

병렬 장면은 `replicate_physics=False`인 일반 USD clone과 GPU PhysX를 사용한다. 원본 RB-Y1 USD의 wheel collision group 4개는 각 환경에 복제되지만, 자체 충돌을 끈 구성에서만 runtime 복제본을 비활성화한다. 원본 USD는 수정하지 않으며 전역 지면과 환경 간 collision filter를 유지한다.

4환경 검사에서는 env 0 plug를 env 1 palm 위치로 옮긴 음성 대조에서 필터 전후 palm 힘과 금지 접촉 하중이 모두 0 N이었고 어느 환경도 종료되지 않았다. reset 뒤 env 0 plug를 같은 환경의 palm에 접촉시킨 양성 대조에서는 env 0의 금지 접촉 하중만 임계값을 넘고 env 0만 abort됐으며, env 1–3은 episode step을 이어 갔다. 이 검사는 환경 간 접촉 격리와 환경별 종료 경로의 근거이며 학습 성능의 근거가 아니다. 세부 항목은 [병렬 장면 검사](evidence/parallel-scene-probe.json)에 둔다.

## 데이터와 에셋

공식 RB-Y1 USD, 기본 그리퍼, NVIDIA 작업 환경 및 조립 벤치마크 자료를 재사용한다. 시각 에셋과 동역학 에셋의 역할을 구분하고 조립 구멍이 충돌 형상에도 남아 있는지 확인한다. 다운로드한 에셋은 런타임 캐시에 두며 재배포 권한이 확인되지 않은 파일을 저장소에 넣지 않는다.

공개 시연은 해당 로봇·과제의 원본 데이터다. RB-Y1 성공 시연으로 표시하지 않는다. 합성한 시연은 원본 시연 ID 단위로 학습·평가를 분리하고 물리 재생과 독립 성공 판정을 통과해야 학습용 성공 데이터에 포함한다.

## 비교 실험

- 기준 제어 / 기준 제어 + 제한된 잔차 정책
- 지지팔 고정 / 양팔 협조
- 관측 입력 및 마찰·질량·지연 랜덤화 제거 실험
- 학습에 쓰지 않은 위치·각도와 물성 조합

첫 비교 규모 제안은 학습 시드 3개 각각에 미사용 조건 200회다. 조건 구성·시드·체크포인트 선택 기준은 실행 전에 고정한다. 성공률, 힘 최대값, 복구율, 소요 시간, 재시도 횟수를 시드별로 보고한다. 성공률이 높은 시드 하나만 선택하지 않는다.

현재 남은 필수 비교는 접촉이 생기는 잼 난이도와 초기 오프셋을 먼저 고정하고, 여러 seed로 규모 있는 잔차 정책 학습을 수행한 뒤, 학습에 쓰지 않은 조건에서 zero-residual 기준 제어와 같은 재시도 예산으로 평가하는 것이다. 3-seed nominal 기록과 1-iteration PPO smoke는 이 비교를 대체하지 않는다.

## 실행 환경

Isaac Sim 5.1 / Isaac Lab 2.3 / Python 3.11을 별도 원격 작업 디렉터리에 구성한다. 기존 Brev 프로젝트의 가상환경이나 데이터를 덮어쓰지 않는다. 물리 시간 간격은 1/120초, 제어 decimation은 4로 제어 주기는 1/30초다. 실행한 코드 SHA·설정·에셋 SHA·GPU·라이브러리 버전·제어 주기·물리 시간 간격을 결과와 함께 저장한다. trace와 영상은 물리 실행의 진단 근거이며, 독립 평가기의 조립 완료 조건을 통과한 실행만 성공으로 기록한다.
