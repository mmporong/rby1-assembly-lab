# 실험 계약

## 문제와 완료 기준

RB-Y1 M v1.2가 한 손에 하우징, 다른 손에 방향성이 있는 플러그를 잡고 상대 자세를 조절해 삽입한다. 삽입이 막히면 후퇴·재정렬·재삽입한다. 첫 실험에서는 베이스를 고정하고 두 팔의 기여를 분리해 평가한다.

부품은 자유 강체다. 그리퍼와 물체 사이에 고정 조인트, 키네마틱 추종, 매 스텝 위치 덮어쓰기를 넣지 않는다. 리셋에서만 초기 상태를 지정한다. 파지 후 접촉·상승·상대 위치를 검증한 에피소드가 조립 단계로 들어간다.

완료는 평가기가 실제 삽입 깊이, 횡방향 오차, 각도 오차, 유지 시간, 파지, 힘 제한, 금지 접촉을 함께 판정한다. 제어기의 `done` 단계나 보상값만으로 성공 처리하지 않는다. 수치와 단위는 `configs/task.json`에 둔다. 해당 수치는 시뮬레이션 설계 가정이며 제조사 허용 하중이나 실측 교정값이 아니다.

## 개발 순서

1. 공식 모델·그리퍼 및 공개 환경 에셋의 출처·해시·USD 물리 구성을 검사한다.
2. 한 환경에서 낙하·정지·그리퍼 개폐·부품 파지·조립을 실행한다.
3. 기준 제어기의 실패 조건을 고정하고 작은 양팔 보정량을 출력하는 잔차 정책을 학습한다.
4. 고정 지그, 지지팔 고정, 양팔 순응을 비교한다. 기준 제어기도 동일한 재시도 예산으로 비교한다.
5. 검증된 실행만 시연 데이터로 보존하고 필요에 따라 영상 관측 정책으로 확장한다.

## 관측 경계

초기 상태 기반 학습은 잡음을 더한 시뮬레이터 자세를 사용하고 `simulator_state_with_noise`로 기록한다. RGB-D 추정기를 실행한 관측만 `estimated_pose`로 기록한다. 접촉 센서의 힘은 손목 6축 F/T 센서와 동일하지 않으므로 접촉력 대용값임을 명시한다. 평가용 정답 깊이·접촉과 정책의 관측을 각각 보관한다.

현재 잔차 정책과 달리 기준 제어기·단계 전환은 정답 상태를 사용한다. 이 구성의 성능을 센서 오차에 대한 전체 시스템의 강건성으로 해석하지 않는다. 향후 관측 추정기를 연결할 때 기준 제어기의 입력도 함께 교체해야 한다. 자체 충돌은 꺼져 있고 금지 접촉은 net force 및 target-contact 차이의 프록시로 검사하므로, 접촉력 상쇄나 자체 충돌 검출까지 보장하지 않는다.

## 데이터와 에셋

공식 RB-Y1 USD, 기본 그리퍼, NVIDIA 작업 환경 및 조립 벤치마크 자료를 재사용한다. 시각 에셋과 동역학 에셋의 역할을 구분하고 조립 구멍이 충돌 형상에도 남아 있는지 확인한다. 다운로드한 에셋은 런타임 캐시에 두며 재배포 권한이 확인되지 않은 파일을 저장소에 넣지 않는다.

공개 시연은 해당 로봇·과제의 원본 데이터다. RB-Y1 성공 시연으로 표시하지 않는다. 합성한 시연은 원본 시연 ID 단위로 학습·평가를 분리하고 물리 재생과 독립 성공 판정을 통과해야 학습용 성공 데이터에 포함한다.

## 비교 실험

- 기준 제어 / 기준 제어 + 제한된 잔차 정책
- 지지팔 고정 / 양팔 협조
- 관측 입력 및 마찰·질량·지연 랜덤화 제거 실험
- 학습에 쓰지 않은 위치·각도와 물성 조합

첫 비교 규모 제안은 학습 시드 3개 각각에 미사용 조건 200회다. 조건 구성·시드·체크포인트 선택 기준은 실행 전에 고정한다. 성공률, 힘 최대값, 복구율, 소요 시간, 재시도 횟수를 시드별로 보고한다. 성공률이 높은 시드 하나만 선택하지 않는다.

## 실행 환경

Isaac Sim 5.1 / Isaac Lab 2.3 / Python 3.11을 별도 원격 작업 디렉터리에 구성한다. 기존 Brev 프로젝트의 가상환경이나 데이터를 덮어쓰지 않는다. 실행한 코드 SHA·설정·에셋 SHA·GPU·라이브러리 버전·제어 주기·물리 시간 간격을 결과와 함께 저장한다. GPU 물리 실행을 확인하기 전에는 정적 USD 검사나 단위 테스트를 조립 성공으로 기록하지 않는다.
