# 학습 전이 0개로 종료된 첫 실행

참조 제어기 사전 검사는 네 조건 모두 엄격 성공을 통과했다. 초기 정책의 평가 뒤 첫 학습 스텝을 기록하려는 시점에 원시 환경에 없는 `get_observations()`를 호출해 종료됐다. 이 함수는 RSL 래퍼에만 있다. 실제 학습 전이와 PPO 업데이트는 모두 0개이며 다중 조건 학습과 최종 비교는 시작하지 않았다.

원래 보고서·조건 계약·실행 소스·전체 참조 및 초기 평가 trace를 보존했다. 원본 묶음과 공개 gzip의 해시는 [회수 기록](recovery.json)에 연결했다. 첫 실행의 성공 기록은 수정 실행의 결과에 합산하지 않는다.

수정은 학습 기록기가 정책에 반환된 79차원 관측 캐시를 스텝 전에 복제해 읽도록 바꾼 것이다. 자동 리셋 후 버퍼가 덮여도 해당 행동을 만든 입력을 보존하며, 기존 terminal snapshot과 대조한다. 물리·보상·초기 가중치 seed·학습량·평가 조건은 바꾸지 않았다. 같은 인스턴스와 $6 예약을 공유하고 원래 자동 종료 시각을 연장하지 않았다.
