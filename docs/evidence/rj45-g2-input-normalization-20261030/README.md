# RJ45 G2 입력 정규화 진단

## 목적

축별 손실 가중치만 적용한 BC 정책이 같은 시연 궤적에서도 충분히 적합되지 않았다. 입력 79차원의 크기 차이가 최적화를 방해하는지 확인하기 위해, 기존 조건을 그대로 재현한 A와 학습 데이터 통계로 입력을 정규화한 B를 한 번씩 비교했다.

두 조건은 ELU MLP 구조, 초기 파라미터, 난수 상태, Adam 학습률 `1e-3`, 2,000회 업데이트, 축별 가중 손실을 동일하게 유지했다. B에서 바뀐 것은 입력 변환뿐이다. 평균과 표준편차는 395개 학습 행에서 계산했으며, 표준편차 하한은 실행 전에 `1e-4`로 고정했다.

## 결과

| 조건 | 원 좌표 MSE | 축 균형 MSE | 판정 |
| --- | ---: | ---: | --- |
| A · 축별 가중 손실, 기존 입력 | `2.1612e-6` | `0.9298` | 이전 결과 재현 |
| B · 축별 가중 손실, 입력 정규화 | `3.4301e-7` | `0.1539` | 사전 기준 PASS |
| C · B에서 이전 명령 12열 제거 | `7.4652e-7` | `0.2866` | B 대비 MSE `2.176×` |
| D · B에서 추정 상대 자세 7열 제거 | `3.6328e-7` | `0.1470` | B 대비 MSE `1.059×`, 보류 |

B의 원 좌표 MSE는 A의 `15.87%`, 상수 평균 기준의 `14.57%`였다. 모든 출력축의 MSE가 해당 축 상수 평균 기준의 `1.10배` 이내였고, 사전에 정한 조건을 모두 만족했다. 마지막 다섯 구간의 손실은 단조 감소하지 않았지만 이 항목은 실행 전에 판정 기준이 아닌 관찰값으로 정했다.

C에서는 이전 명령 입력을 제거하자 MSE가 B의 `2.176배`로 증가했다. 따라서 이 궤적 회귀에서는 이전 명령 열이 적합에 유용한 정보를 포함한다. D는 B 대비 `1.10배` 악화 기준에 미치지 않아, 추정 상대 자세 열의 기여도는 이 실험만으로 판단하지 않는다.

## 재현성과 제한

- A가 이전 축 스케일링 결과의 초기 파라미터, 초기 난수 상태, 최종 파라미터 해시와 MSE를 재현한 뒤에만 B를 실행했다.
- 입력 통계의 `float64` 원본과 실제 학습·추론에 사용하는 `float32` 평균·스케일·마스크를 프로토콜과 체크포인트에 저장했다.
- 체크포인트를 다시 불러온 추론 결과가 395개 행 전체에서 최종 파라미터 평가 결과와 일치하는지 확인했다.
- 저장된 체크포인트는 `diagnostic_not_main_bc`이며, 정규화 정보가 없거나 배열 해시·형상·유한성 검사를 통과하지 못하면 로더가 거부한다.
- 이 결과는 같은 학습 궤적에 대한 회귀 적합 개선이다. 폐루프 물리 삽입 성공, 미사용 조건 일반화, 상태 피드백의 인과 효과, PPO 기여를 입증하지 않는다.

다음은 고정 train 조건의 1환경 PhysX 폐루프 진단이다. 입력 전처리를 제어 루프에 연결한 뒤, A/B를 같은 초기 상태·seed로 비교해 독립 삽입 성공·안정 유지·중단·접촉 하중을 확인한다. 해당 검증을 통과한 뒤 전체 시연 데이터의 BC 재학습과 기준 제어·BC·PPO·BC→PPO 비교에 적용한다. 현재 한 궤적의 진단 체크포인트는 본실험 초기화에 사용하지 않는다.

## 정본

- `protocol.json`: 실행 전에 동결한 데이터·소스·런타임·정규화·판정 계약
- `result.json`: A/B 및 조건부 C/D의 수치, 체크포인트 해시, 판정 결과
- `scripts/run_rj45_g2_input_normalization_probe.py`: 실행기와 체크포인트 추론 로더
- `tests/test_run_rj45_g2_input_normalization_probe.py`: 정규화·무결성·중단 조건·소규모 실제 학습 검사
