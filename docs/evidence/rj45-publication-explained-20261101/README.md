# RJ45 게시 영상의 목적·차이 설명 수정

사용자가 v2의 과도한 확대와 두 실행의 차이를 이해하기 어렵다는 점을 지적했다. v3는 촬영한 원본 화면을 자르지 않고 두 팔의 그리퍼와 작업 공간을 함께 보여준다. 재촬영·새 학습·물리 재실행은 없다.

- [미리보기](../../media/rj45/publication-20261101-v3/preview.png)
- [촬영 원본과 판정 근거](../rj45-publication-20261101/README.md)

프로젝트의 목표는 한 손으로 지지하는 어댑터에 다른 손으로 플러그를 삽입할 때, 위치 추정 오차를 학습 보정으로 줄일 수 있는지 검증하는 것이다. 현재 확인된 성과는 시뮬레이션 과제와 비교·기록·판정 경로의 구축이다. 원평가 8조건에서 다중 오차 PPO 3/8, 단일 오차 PPO 2/8, 기본 제어 2/8로 학습의 개선 효과와 일반화를 입증하지 못했다.

대표 영상에서는 두 방법 모두 약 12mm 깊이에 도달했다. PPO의 종료 횡오차는 33.509179µm, 기본 제어는 64.711639µm였다. 마지막 제어 시점에서 PPO는 7개 판정 조건을 모두 통과했고, 기본 제어는 횡오차와 안정 유지 조건을 통과하지 못해 24초 제한으로 종료했다. 50µm는 프로젝트 기준이며 제조사 규격이나 실물 조립의 요구 성능을 입증하는 값이 아니다.

차이는 동작만으로 알아보기 어렵다. v3는 원시 프레임 기록의 횡오차·깊이와 인과적으로 표시한 30Hz 안정 유지 시간을 추가했다. 막대는 0~100µm 측정값 그래픽이며 실제 부품의 이동을 과장한 그림이 아니다. 100µm 초과는 숫자를 보존하고 마커만 끝점에 제한한다. 초기 정책 입력 무효 구간은 자세 준비로 표시한다.

ASS 시각은 1/100초 단위로 내림하여 인접 이벤트가 겹치지 않게 했다. 60fps의 모든 프레임 PTS에서 해당 프레임의 값 하나만 표시되는지 검증했다. 두 원본은 같은 시작 시각과 1배속을 유지하고, 먼저 종료한 영상은 결과 카드로 바뀐다. 로봇 프레임을 반복하거나 시간 보간하지 않았다.

이 영상은 실험 환경과 한 사례의 판정을 설명하는 자료다. PPO가 실용적인 조립 성능을 개선했거나 두 동작의 차이가 육안으로 뚜렷하다고 주장하지 않는다. 이전 v2 자료는 보존했다.
