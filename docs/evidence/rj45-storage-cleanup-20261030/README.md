# 학습 자료 용량 정리

보관할 추출본과 내용이 같은 회수 압축본 11개만 제거했다. 학습 데이터, 모델 checkpoint, bank, 원시 trace, 실패 영상, 실행 로그와 기존 provenance 파일은 유지했다. 다른 프로젝트·Brev 인스턴스·전역 설치 캐시는 변경하지 않았다.

- 압축본 11개, 총 734,086,847 bytes를 제거했다.
- 압축본의 1,218개 member와 추출본을 size·SHA-256·파일 종류·안전 경로 기준으로 전수 대조했다.
- 삭제 직전과 직후를 별도 verifier가 검증했다. 삭제 후 보존 파일 1,218개의 SHA·size·mode가 원장과 모두 같았다.
- 제거한 파일의 할당 블록은 734,142,464 bytes였다. 정리 직전·직후 파일시스템 가용 공간 차이는 734,138,368 bytes, 약 700 MiB였다. 직후 여유는 약 2.35 GiB였다. 이후 공간은 다른 작업에 따라 달라질 수 있다.

## 정본과 검증 기록

[summary.json](summary.json)에 압축본별 원래 경로·SHA·크기와 보존한 추출본 경로를 기록했다. 압축본 member의 mode·mtime·uid/gid 등 메타데이터도 로컬 원장에 보존했다. 기존 추출본의 권한은 바꾸지 않았다. 압축 파일 자체의 바이트는 보관하지 않으므로 압축 파일 해시는 과거 회수 기록 대조에 사용하고, 현재 내용 검증에는 보존한 member 해시를 사용한다.

대용량 학습 자료와 상세 member 원장은 Git 비추적 로컬 자료다. 원장·삭제 영수증·독립 검증 파일은 아래 폴더에 있다. 각 파일의 SHA는 summary에 남겼다.

```bash
cd "$HOME/rby1-assembly-lab"
ls artifacts/cloud/rj45-resume-20261030/storage-cleanup/
```

대응 추출본을 확인하지 못한 소스 압축본, 내용 해시가 서로 다른 HDF5와 고유 자료는 제거하지 않았다. 후속 정리도 보존할 정본과 내용·메타데이터를 확인한 뒤 수행한다.
